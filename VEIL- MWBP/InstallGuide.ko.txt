MWBP 1.2.0-rc.7 — 설치 안내

PowerToys의 Mouse Without Borders를 기반으로 수정한 비공식 프로젝트입니다. Microsoft와 제휴하거나 보증받은 제품이 아닙니다.

VEIL-MWBP-Setup.exe를 실행하고 ‘MWBP 설치’를 누른 뒤 Windows 승인 창에서 허용하세요.
별도 PowerToys나 .NET 런타임 설치는 필요하지 않습니다.

각 PC에 같은 버전을 설치하세요. ‘PC 찾기’에서 다른 PC를 선택하고, 두 화면의 확인 코드가 같으면 양쪽에서 승인하세요.
목록에 PC가 없으면 해당 PC의 이름 또는 IPv4 주소를 직접 입력할 수 있습니다.
모니터를 끌어 실제 위치에 맞추고 가장자리를 붙인 뒤 적용하세요.

‘파일 보내기…’에서 받는 PC와 파일을 고르면 그 PC의 설정된 수신 폴더로 보냅니다.
옵션의 ‘자동 전송 300MB 제한’은 기본으로 켜져 있습니다. 큰 파일은 파일 보내기나 드래그로 전송하세요.
직접 보내기·클립보드의 전송 동작을 동일하게 사용하려면 보내는 PC와 받는 PC 모두 같은 버전으로 설치하세요.

기존 연결·모니터 배치·단축키·설정·전송 기록은 유지됩니다.
설치 후 시작 메뉴의 Mouse Without Borders Plus로 실행하세요. Windows의 설치된 앱 목록에서도 제거할 수 있습니다.
제거 시 연결·설정을 보존할 수 있으며, 삭제 여부는 별도로 선택합니다.

관리자 앱과 UAC 화면 입력에는 Windows 승인을 받은 SYSTEM 입력 서비스가 사용됩니다.
연결된 PC에 관리자 화면의 입력 능력을 위임하며, 이 Windows 계정의 다른 앱이 이 권한을 악용할 수 있습니다.
Windows 정책으로 서비스가 금지된 경우 일반 입력·연결·파일 공유는 별도로 사용할 수 있습니다.

RC7은 유휴 상태를 갱신할 때 임의로 커서를 흔들고 기다리던 동작을 없애고, 앱과 수신 처리의 실행 우선순위를 조정한 후보입니다.
앞선 후보의 일반 마우스 이동·보호 입력 잠금 분리, 텍스트·이미지 클립보드 본문·입력 TCP 분리, 파일 전송 잠금·텍스트·이미지 전송 분리도 유지합니다.
동일한 클립보드 내용의 중복 전송을 줄이고, 이전 PC의 커서 숨김·클립보드 알림을 비동기로 보냅니다. 연결 대상이 바뀌면 오래된 연결로 보내지 않도록 확인합니다.
이 변경은 항상 적용되며, 복구 버튼을 눌러야 활성화되는 최적화가 아닙니다. 실제 체감 지연의 해소를 보장하지는 않습니다.

‘마우스 입력 복구’는 이 PC의 대체 커서를 끄고 입력 훅과 연결을 다시 시작하도록 요청합니다.
공유가 잠시 끊기며 기존 연결·배치·단축키·파일 공유 설정은 유지합니다. Windows 마우스 키·숫자패드·서비스 권한은 바꾸지 않습니다.
‘Windows 커서 사용’은 Windows 마우스 키를 켜고 대체 커서를 끄는 별도 표시 설정이며, 숫자 키패드 동작에 영향을 줄 수 있습니다.

현재 패키지는 1.2.0-rc.7 배포 후보입니다. 최종 전체 시험 결과는 해당 버전의 공개 릴리스를 확인하세요. 이전 버전의 결과를 이 후보의 검증으로 세지 않습니다.
세 PC의 동일 버전 적용·실사용 수락·지속 지연 해소는 아직 확인하지 않았습니다. 실제 확인한 사용 환경은 Windows 11 x64입니다.
서명되지 않은 EXE이므로 Windows 승인 창에 게시자가 ‘알 수 없음’으로 표시될 수 있습니다. Microsoft의 공식 제품이 아닙니다.
라이선스와 제3자 고지는 EXE의 정보 화면과 배포 폴더에 포함됩니다.
