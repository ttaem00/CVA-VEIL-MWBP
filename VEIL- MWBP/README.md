# VEIL MWBP

Windows PC 사이에서 마우스·키보드·클립보드·파일을 공유하는 Mouse Without Borders Plus의 배포 프로젝트입니다.

사용자에게 전달할 파일은 **`VEIL-MWBP-Setup.exe` 하나**입니다. 실행 → **MWBP 설치** → Windows 승인으로 설치합니다. PowerToys, .NET 런타임, ZIP 해제나 명령 입력이 필요하지 않습니다. Windows 권한 승인은 생략하지 않습니다.

기존 연결·모니터 배치·단축키·전송 기록은 앱의 기존 설치 경로에서 보존합니다. 실행 파일·서비스·설정의 내부 이름을 바꿔 별도 설치본을 만드는 방식으로 리브랜딩하지 않습니다.

## 재빌드

개발 컴퓨터에 Windows, PowerShell 7, .NET SDK 10.0.403이 필요합니다. `global.json`의 고정 SDK로 빌드하며 설치 EXE에는 .NET 10.0.14 보안 패치를 포함합니다. 사용하는 PC에는 SDK가 필요하지 않습니다.

```powershell
pwsh -NoProfile -File './VEIL- MWBP/Build-Release.ps1' -Destination 'C:/build/VEIL- MWBP'
```

출력 폴더는 비어 있어야 합니다. 설치 EXE와 SHA256, 라이선스·안내가 생성됩니다. 별도 MSI나 설치 스크립트를 사용자에게 실행시키지 않습니다. 설치 EXE와 앱은 동일 바이너리이며, 설치 후에는 보호된 기존 경로의 앱을 일반 권한으로 실행합니다.

## 배포 범위

현재 버전은 **1.2.0-rc.4**입니다. 자동 클립보드 파일의 300MB 제한 옵션과 명시적으로 PC를 골라 보내는 버튼을 포함합니다. 설정 파일 작업·다른 PC의 송신·파일 취소와 일반 마우스 이동의 불필요한 잠금 결합을 제거했습니다. 명시 송신은 상대의 설정된 수신 폴더를 사용하며, 이전 버전의 상대는 이 구분을 처리하지 않으므로 모든 PC를 같은 버전으로 설치해야 합니다. 소스 ZIP에는 빌드에 필요한 공개 코드·시험·라이선스만 포함하고 `.git`, 작업 기록, 실제 사용자 설정, 보안 키, 전송 기록, 개인 PC 업데이트 스크립트는 포함하지 않습니다.

공개 소스와 설치 EXE의 배포 대상은 [ttaem00/CVA-VEIL-MWBP](https://github.com/ttaem00/CVA-VEIL-MWBP)입니다. 공개 코드 서명 인증서는 이 프로젝트에 포함하지 않습니다.

## 검증 상태

직전 RC2의 Windows x64 전체 시험은 409개 중 408개 통과, 기존 제외 1개, 실패 0개입니다. 실제 단일 EXE 설치 → 설정 보존 제거 → 재설치와 기존 연결·네 모니터 배치 복원, 2GB 파일의 복사 중 정상 종료 → 44MB에서 복원 → 재개 완료·양단 내용 해시 일치를 확인했습니다. RC3의 전체 회귀는 424개 중 423개 통과·기존 제외 1개·실패 0개입니다. 새 한국어 체크박스와 두 동작 버튼의 100·150·200% 및 큰 글꼴 레이아웃 3건도 통과했습니다. 암호화 loopback으로 명시 송신의 수신 준비·목록 수락·실제 파일 바이트와 원본 보존을 확인했고, 별도 에이전트 적대검토를 통과했습니다. 이 로컬 검증을 세 PC 새 버튼 실사용 성공으로 확대하지 않습니다.

RC4 전체 회귀는 437개 중 436개 통과·기존 제외 1개·실패 0개입니다. 설정 디스크 작업을 막아도 입력 설정 접근이 계속되는지, 다른 PC의 실제 loopback 송신을 막아도 독립 대상의 마우스 프레임이 도착하는지, 동기 저장·최신 변경·프레임 원자성이 보존되는지를 검증했고 별도 에이전트가 소스 적대검토를 통과시켰습니다. RC4의 실제 세 PC 적용과 체감 지연 개선은 아직 확인하지 않았습니다.

현재 EXE는 서명되지 않았으므로 Windows 승인 창에 게시자가 ‘알 수 없음’으로 표시될 수 있습니다. 정식 서명·공개 발행은 아직 하지 않았습니다. PC 간 UAC 키보드 취소는 확인했으며 UAC 마우스 클릭은 별도 확인이 필요합니다. 이 후보를 모든 요구사항의 최종 수락이나 안정 버전 보증으로 표시하지 않습니다.
