Code signing policy

확인일: 2026년 11월 9일

현재 상태

현재 공개 릴리스 1.2.0-rc.17의 Windows 설치 파일에는 공인 디지털 서명이 없습니다. SignPath Foundation의 무료 오픈소스 서명 지원을 위한 자료를 준비하고 있으며, 지원 선정·인증서 제공·서명 서비스 활성화는 아직 확정되지 않았습니다.

이 페이지가 존재한다는 이유로 현재 파일이 서명되었거나 Microsoft Store 심사를 통과했다고 판단하지 마세요. 현재 릴리스의 게시자 경고 안내와 다운로드 출처 확인 절차는 계속 적용됩니다.

서명 도입 시 적용할 원칙

서명 대상은 공개 정본 저장소의 검토된 소스에서 빌드한 MWBP 산출물로 한정합니다. 소스 작성·리뷰와 실제 서명 승인 담당자의 역할을 확인하고, 서명 요청마다 유지관리자의 명시적인 승인을 거칩니다. 승인자와 공급자 정보는 서명 지원이 확정되면 이 페이지에 공개합니다.

최종 실행 파일이 만들어진 후 서명을 적용하고 유효성을 확인한 다음 SHA256을 계산합니다. 서명 후 파일을 다시 빌드하거나 변경하지 않으며, 이전 공개 버전 URL의 파일을 교체하지 않습니다. 서명되지 않은 파일을 서명 완료 산출물로 배포하지 않습니다.

공인 코드 서명은 파일의 게시자와 무결성을 확인하는 수단입니다. 직접 다운로드한 새 실행 파일에 SmartScreen 경고가 즉시 사라지는 것을 보장하지 않습니다.

개인정보와 문의

앱이 처리하는 정보는 개인정보처리방침에서 확인할 수 있습니다. 서명 관련 문제는 프로젝트 지원 페이지에 공개 가능한 파일명·버전·검증 결과만 포함하여 문의해 주세요.
